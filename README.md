# METAL SLUG · 合金弹头（像素版）

单文件 HTML5 像素风横版射击游戏，零依赖，Canvas 手绘像素 + Web Audio 合成音效。

**在线试玩：https://slatinwine.github.io/metal-slug/**

## 操作

| 按键 | 功能 |
|------|------|
| ←→ / A D | 移动 |
| ↑ / W | 朝天瞄准 |
| ↓ / S | 蹲下（可躲敌方平射子弹） |
| Z / J | 射击 |
| X / K / 空格 | 跳跃 |
| C / L | 手雷 |
| P | 暂停 |
| M | 音乐开关 |

触屏设备自动显示虚拟按键。

## 玩法

- 击毙步枪兵、冲锋兵、军官，营救被绑人质（+500 分并掉落补给）
- 打爆木箱拾取 **H 重机枪**（150 发）与手雷包
- 蹲下与沙袋掩体可规避敌方子弹，终点击败坦克 Boss 即通关
- 最高分自动存档（localStorage）
